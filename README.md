1. Quel est le projet ? 

TechDigest est un mini assitant qui récupère toutes les actualités technologiques, les filtres et les résumes grâce à l'IA pour avoir un journal quotidien de celle-ci.



2. Pourquoi ce projet ? 

L'objectif est de pouvoir recevoir un résumé d'actualités technologique hebdomadaire.

3. Comment l'utiliser ?

Quelques étapes simples :

installer les dépendances ;
créer le fichier .env ;
lancer le projet.
